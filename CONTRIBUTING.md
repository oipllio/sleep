# Contributing

Thanks for your interest in improving Sleep.

## How to Contribute

1. Fork the repository.
2. Create a branch for your change.
3. Keep the project dependency-free unless there is a clear reason to add a library.
4. Test interactions in a browser, including mobile-size screens.
5. Open a pull request with a short description of the change.

## Good First Contributions

- Improve accessibility and keyboard interaction.
- Refine mobile layout and animation performance.
- Add new copy variants for the invitation flow.
- Improve documentation and examples.

## Maintainer Notes

The maintainer reviews changes for readability, browser compatibility, and whether the interaction still works as a simple static web page.
