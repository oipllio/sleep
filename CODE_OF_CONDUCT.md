# Code Of Conduct

## Our Standard

This project is intended to be a friendly learning example for small static web pages. Contributors and users are expected to communicate respectfully, stay focused on the project, and make room for beginners to ask practical questions.

Helpful behavior includes:

- explaining changes clearly
- giving specific, actionable feedback
- respecting different experience levels
- keeping discussions relevant to the repository

Unacceptable behavior includes:

- harassment, insults, or personal attacks
- discriminatory language or conduct
- spam, trolling, or intentionally disruptive comments
- sharing private information without permission

## Enforcement

The maintainer may edit, hide, or remove comments and contributions that do not meet this standard. Repeated or severe violations may result in being blocked from participating in the project.

If you see a problem, contact the maintainer at:
