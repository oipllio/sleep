# Sleep

Sleep is a static interactive Chinese invitation page. It uses plain HTML, CSS, and JavaScript to create danmaku-style messages, floating decorations, click fireworks, and playful button interactions.

Live demo: https://oipllio.github.io/sleep/

## Features

- No build step or external runtime
- Mobile-friendly static page
- Danmaku-style animated text
- Floating decorative effects
- Fireworks interaction on confirmation
- Playful moving "no" button behavior
